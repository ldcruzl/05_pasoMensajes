# Práctica: Paso de Mensajes - Sistemas Operativos

## Información del curso

- **Curso:** Sistemas Operativos
- **Docente:** Ing. Hugo Manuel Barraza Vizcarra
- **Jefe de práctica:** Ing. Jimmy Muñoz Miranda
- **Tema:** Paso de mensajes (colas de mensajes System V)

## Objetivos

- Implementar mecanismos de paso de mensajes en GNU/Linux.
- Compilar y ejecutar programas que usan colas de mensajes System V.
- Explicar el comportamiento bloqueante/no bloqueante de `msgrcv`/`msgsnd`.

## Contenido

- Programas en C que usan colas de mensajes System V (`msgget`, `msgsnd`, `msgrcv`, `msgctl`).
- Análisis del comportamiento bloqueante y no bloqueante de las llamadas.

## Entorno de desarrollo

- Sistema operativo: Ubuntu (máquina virtual)
- Lenguaje: C
- Compilador: gcc
